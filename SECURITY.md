# Security and safety reporting

This repository is an academic research prototype. It is **not** a clinical decision-support product and must not be used to estimate an individual's suicide risk or make autonomous treatment decisions.

Please report:
- credential or secret exposure;
- unsafe bypasses of the Safety Supervisor;
- provenance failures that could attach a claim to the wrong source;
- code execution vulnerabilities in future executable Paper Skills.

For ordinary software defects, open a GitHub issue. For a vulnerability that should not be disclosed publicly, use GitHub's private vulnerability reporting if it is enabled for the repository.

Do not include identifiable patient or participant information in issues, pull requests, fixtures, or logs.
