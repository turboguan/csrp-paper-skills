# v0.3 status — Evidence-Family Benchmark

## Completed in this first v0.3 step

- Defined claim pairs rather than paper pairs as the primary scientific evaluation unit.
- Fixed the relation vocabulary: `SUPPORTS`, `CONTRADICTS`, `QUALIFIES`, `NOT_COMPARABLE`, `UNRELATED`.
- Defined a two-reviewer + adjudication rule before a relation can be treated as benchmark gold.
- Selected three candidate evidence families.
- Built an initial 13-paper candidate manifest.
- Added explicit handling for same-programme / same-dataset dependency.
- Wrote the first matched benchmark protocol.

## What is not complete

- The 10 new candidates are not yet Paper Skills.
- Candidate claims have not yet been independently expert-validated.
- There are no adjudicated gold claim-pair labels yet.
- The four architecture runners are not yet connected to one matched LLM/retrieval setup.
- No v0.3 performance result should be reported.

## Immediate next milestone

Convert the **means-restriction family first**, because it contains the cleanest scientific contrast:

- Hong Kong short-term controlled intervention (2010)
- New Taipei short-term quasi-experimental intervention (2015)
- New Taipei long-term controlled interrupted time-series follow-up (2021)
- East/Southeast Asia regional trend context (2014)

This family is especially useful for testing whether a system incorrectly calls short-term benefit versus long-term null evidence a simple contradiction, rather than reasoning about follow-up window, implementation fidelity, study design and scope.
