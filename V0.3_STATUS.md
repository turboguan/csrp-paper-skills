# v0.3 status — Evidence-Family Benchmark

- Expanded the repository into a normal runnable source tree: `src/`, `tests/`, `schemas/`, `scripts/`, `sample_skills/`, `real_skills/` and `benchmark/v0.3/`.
- Removed the embedded v0.2 project ZIP from the v0.3 branch.
- Defined **claim pairs**, rather than paper pairs, as the primary cross-paper evaluation unit.
- Fixed the relation vocabulary:
  - `SUPPORTS`
  - `CONTRADICTS`
  - `QUALIFIES`
  - `NOT_COMPARABLE`
  - `UNRELATED`
- Defined a two-reviewer + adjudication rule before a relation can be treated as benchmark gold.
- Selected three evidence families and built an initial 13-paper candidate manifest.
- Added explicit same-programme / same-dataset dependency handling.
- Implemented the first matched benchmark protocol and candidate query set.
- Converted the **means-restriction / charcoal** family into four structured paper records:
  - Hong Kong short-term controlled intervention (2010)
  - New Taipei short-term quasi-experimental intervention (2015)
  - New Taipei long-term controlled interrupted time-series follow-up (2021)
  - East/Southeast Asia regional time-trend context (2014)
- Added a second-pass source-verification packet for the means-restriction family.
- Added four candidate claim pairs and a blinded two-reviewer adjudication workflow.
- Added a script that converts completed reviewer sheets into adjudicated relation records.
- Added a runnable four-arm evaluation harness that records unimplemented baselines as `not_ready` rather than fabricating outputs.

## Human gate — next required step

The immediate milestone is now **expert adjudication of the means-restriction family**.

Reviewers should use:

- `benchmark/v0.3/MEANS_BLINDED_REVIEW_PACKET.md`
- `benchmark/v0.3/means_restriction_review_sheet.csv`
- `benchmark/v0.3/GOLD_STANDARD_POLICY.md`
- `benchmark/v0.3/RELATION_LABEL_GUIDE.md`

Once two independent reviewers complete the sheet, run:

```bash
python scripts/build_gold_relations.py \
  --input benchmark/v0.3/means_restriction_review_sheet.csv \
  --output benchmark/v0.3/means_restriction_gold.jsonl \
  --family-id means_restriction_charcoal
```

Only adjudicated records are eligible for benchmark scoring.
