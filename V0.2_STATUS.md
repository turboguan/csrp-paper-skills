# v0.2 status

## What is real now

- Five publication records are real CSRP-linked papers with DOI/source metadata.
- Fifteen evidence claims are structured as Paper Skill claims with source anchors.
- The registry, graph, router, domain-agent workspace, Evidence Judge and Safety Supervisor run end to end.
- The real-paper demo creates machine-readable outputs and a graph summary.
- Individual suicide-risk scoring is blocked before evidence retrieval.
- The full automated test suite passes.

## What is not yet a scientific result

- The five records have not yet been independently checked by a suicide-prevention domain expert.
- No LLM reasoning model is being benchmarked in v0.2.
- No claim is made that Paper-as-Skill outperforms RAG or multi-agent baselines.
- Local latency values are implementation telemetry only.
- The five heterogeneous papers are not a meta-analysis sample.
- Cross-paper `SUPPORTS / CONTRADICTS / QUALIFIES` accuracy has not yet been validated against expert gold labels.

## Decision for v0.3

The next useful unit of work is not “add as many papers as possible.” It is to create **matched evidence families** so the central architectural hypothesis becomes testable.

Target: 10–15 papers arranged into 2–3 families with overlapping intervention/exposure, outcome and population definitions. Each claim pair should receive an expert relation label. That dataset becomes the first real cross-paper reasoning benchmark.
