# v0.9 — Suicide-Prevention LLM Demo

## Focus

At this stage, Virtual CSRP remains focused on **suicide-prevention research**. The purpose of v0.9 is not to expand into a generic virtual institute or to run the full organizational benchmark.

The immediate question is simpler:

> **Can the current Virtual CSRP evidence infrastructure be connected to one real LLM and produce useful, provenance-grounded answers across several suicide-prevention research domains?**

## Five-paper live corpus

The first live LLM demo uses the five existing structured CSRP paper records:

1. school/youth mental-health and suicide-prevention leadership programme;
2. spatial-temporal suicide-cluster surveillance;
3. postdischarge caring contact after self-harm;
4. charcoal-access means restriction;
5. celebrity-suicide / media-related effects.

These five records are a **demo corpus**, not a systematic review and not the full CSRP evidence base.

## Six questions

The demo asks one question in each evidence area plus one cross-domain synthesis question.

The system records:

- institutional routing plan;
- retrieved paper IDs;
- final LLM answer;
- claim-level provenance;
- Evidence Judge output;
- Safety Supervisor output;
- input/output tokens;
- LLM calls.

## Architecture used for this smoke test

For simplicity, v0.9 first tests the **Shared-Knowledge Umbrella** path:

```text
Question
  ↓
Virtual CSRP Query Router
  ↓
FixedEvidenceRetriever
  ↓
Shared Paper Skills + Evidence Graph
  ↓
GPT-6.1 Sol institutional synthesis
  ↓
Evidence Judge
  ↓
Safety Supervisor
  ↓
Answer + claim-level provenance
```

This is intentionally **not yet** the A/B/C comparison. Once the live evidence-grounded path is stable, the same questions can be run through all three organizational designs.

## Run

The real demo requires an OpenAI API key supplied only through the environment:

```bash
export OPENAI_API_KEY="..."
export CSRP_REAL_LLM_CONFIRM=1
python -m pip install -e '.[openai]'
python scripts/v09_suicide_prevention_llm_demo.py
```

Do not commit an API key.

## Safety boundary

This is an academic research prototype. It may summarize suicide-prevention evidence, methods, policies and implementation research. It must not autonomously estimate an individual's suicide probability, diagnose, triage or select treatment.

## Interpretation

A successful live demo establishes only that the pipeline can connect structured CSRP evidence to a real LLM with provenance and safety controls. It does not establish superiority over another architecture, systematic-review validity or clinical utility.
