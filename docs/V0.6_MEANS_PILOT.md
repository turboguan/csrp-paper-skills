# Means Restriction Pilot v1

## Goal

Run the first small matched comparison of the three organizational architectures on the same four-paper means-restriction corpus.

### Architectures

1. Functional Multi-Agent Organization
2. Paper-Agent Committee
3. Shared-Knowledge Umbrella

### Corpus

- CSRP-REAL-004 — Hong Kong retail charcoal restriction
- V03-MEANS-002 — 2015 New Taipei short-term intervention
- V03-MEANS-003 — 2021 New Taipei long-term follow-up
- V03-MEANS-004 — East/Southeast Asia regional time trends

## Question design

The pilot has 18 pre-specified questions:

- 5 low-complexity / low-interdependence factual tasks;
- 6 medium-complexity two- or three-paper comparison tasks;
- 5 high-complexity synthesis / decision tasks;
- 2 adversarial unsupported-evidence tasks.

This gives the management-theory experiment an explicit task-demand axis rather than treating all questions as equivalent.

## What can be scored automatically

- paper retrieval recall against pre-specified required papers;
- required-claim provenance recall;
- invalid claim-ID citations;
- correct abstention on unsupported questions;
- LLM calls;
- input/output/total tokens;
- coordination messages.

## What still requires human review

For medium/high synthesis tasks, reviewers should score:

- evidence correctness (1–5);
- cross-paper synthesis (1–5);
- uncertainty handling (1–5);
- relation reasoning (1–5);
- decision quality (1–5);
- whether an unsupported claim is present.

These human ratings are evaluation labels, not replacements for the separately frozen Human Gold relation set.

## Replication

The first real pilot is configured for **3 replicates per architecture × question cell**.

18 questions × 3 architectures × 3 replicates = **162 architecture-query-replicate cells**.

## Real-run guardrails

`scripts/v06_means_pilot_real.py` refuses to run unless:

1. `CSRP_REAL_LLM_CONFIRM=1` is set;
2. `CSRP_ADAPTER_FACTORY=package.module:function` points to a real provider adapter;
3. `benchmark/v0.5/matched_experiment_config.json:model_id` has been frozen;
4. the adapter's `model_id` exactly matches the frozen model ID.

This prevents an accidental mixed-model pilot.

## Current boundary

The 18-question suite and matched runner are ready. A real LLM result should not be generated or reported until one fixed model/version and the required API credential are supplied.
