# v0.7 — Frozen Real-LLM Pilot Configuration

## Frozen model

Means Restriction Pilot v1 is now configured to use:

- Provider: OpenAI
- API: Responses API
- Model ID: `gpt-6.1-sol`
- Service tier: `default`
- Store responses: `false`
- Temperature: `0.0`
- Seed: not used
- Evidence budget: 4 papers
- Total token ceiling: 16,000 tokens per architecture-query cell
- Maximum output per call: 700 tokens
- Maximum LLM calls: 8 per architecture-query cell

The model identifier was frozen on 2026-10-18. If a dated snapshot identifier becomes available before the first paid run, do not silently replace this value; create a new version of the experiment config.

## Why this model

The pilot is an organizational-design experiment, not a model-comparison experiment. One capable general-purpose model is therefore used across all three architectures so model choice is held constant.

## Credential handling

**Never commit or paste an API key into the repository.**

For local execution:

```bash
export OPENAI_API_KEY="..."
export CSRP_REAL_LLM_CONFIRM=1
python -m pip install -e '.[openai]'
python scripts/v07_openai_smoke.py
```

For GitHub Actions, create a repository Actions secret named:

```text
OPENAI_API_KEY
```

The workflow reads the secret only at runtime.

## Two-stage execution

### Stage 1 — smoke test

Run one tiny paid request first:

```bash
python scripts/v07_openai_smoke.py
```

The smoke test verifies:

- credential works;
- account has access to the frozen model;
- Responses API accepts the frozen generation settings;
- provider returns usage metadata;
- returned model ID matches expectations.

### Stage 2 — full pilot

Only after the smoke test succeeds:

```bash
python scripts/v06_means_pilot_real.py
```

The planned pilot is:

- 18 questions;
- 3 organizational architectures;
- 3 replicates;
- 162 architecture-query-replicate cells.

Because Functional and Committee architectures use multiple calls within a cell, the number of API requests is larger than 162. Call count and token use are recorded as coordination-cost outcomes.

## Reproducibility

Local token counting is only a conservative preflight estimate. Provider-reported token usage is authoritative and is used for final budget accounting.

The real pilot must preserve:

- the same OpenAI model ID;
- the same evidence packet per query;
- the same evidence budget;
- the same total token ceiling;
- the same generation settings;
- no architecture-specific hidden retries.

## Scientific boundary

A successful API run is not evidence that one architecture is better. It only produces the outputs needed for automated scoring and blinded human review.
