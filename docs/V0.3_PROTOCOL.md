# v0.3 benchmark protocol

## Scientific question

Does a shared Paper-as-Skill architecture preserve and reason over cross-paper evidence relationships more reliably than matched RAG-only, monolithic-agent, and one-paper-one-agent systems?

## Benchmark unit

The core unit is **a claim pair**, not a paper pair. A single paper can contain multiple claims with different relations to claims in another paper.

## Candidate corpus

Start with 10–15 papers in 2–3 matched evidence families:

- **Means restriction / charcoal burning:** short-term benefit versus longer-term null effects and contextual epidemiology.
- **Media / celebrity suicide:** single-event studies, cross-region studies, reporting-guideline interventions, and meta-analytic evidence.
- **School / youth mental health:** related but non-identical programmes, outcomes, follow-up windows, and possible shared-programme dependence.

## Paper Skill validation

For every candidate paper, human-review:

- population and setting;
- intervention/exposure and comparator;
- outcome definition;
- study design and method;
- effect estimate and uncertainty where available;
- claim wording;
- causal-language allowance;
- limitations and applicability;
- exact provenance anchor.

No paper enters benchmark gold until its relevant claims have been reviewed.

## Claim-pair construction

Generate candidate pairs only when there is a plausible scientific relation. Lexical similarity alone is insufficient.

For each pair, reviewers record:

- population match;
- intervention/exposure match;
- outcome match;
- method comparability;
- timeframe comparability;
- dataset/programme dependency;
- final relation label.

## Gold adjudication

Two blinded reviewers independently label each candidate pair. Disagreements are resolved by adjudication.

Primary labels:

`SUPPORTS`, `CONTRADICTS`, `QUALIFIES`, `NOT_COMPARABLE`, `UNRELATED`.

## Matched architecture benchmark

Compare four systems using the same frozen corpus, query set, base model, retrieval budget, and generation budget wherever technically possible:

1. RAG-only
2. monolithic agent
3. one-paper-one-agent
4. Paper-as-Skill

Primary tasks:

- relation classification;
- multi-paper synthesis;
- contradiction versus heterogeneity resolution;
- population applicability;
- source tracing.

## Primary metrics

- relation accuracy and per-label recall;
- claim-level provenance precision / recall;
- evidence coverage;
- contradiction false-positive rate;
- abstention / calibration;
- safety compliance;
- coordination-message count;
- tokens, calls, latency, and cost.

## Scaling experiment

Increase relevant evidence load while holding the task family fixed:

`1 → 3 → 5 → 10 → 20 → 40` papers.

The main hypothesis is that isolated paper-level reasoning contexts will incur increasing coordination burden and lose more cross-paper relations than a shared-skill workspace. This is a hypothesis, not a current result.

## Exclusion from primary analysis

Exclude or separately analyze:

- duplicate reports from the same dataset/programme;
- papers without adequate source provenance;
- claims whose outcome or population cannot be reliably normalized;
- papers whose target claim cannot be verified from accessible source material.

## Pre-registration intent

Before the final benchmark, freeze corpus version, query set, gold labels, architecture definitions, model/retriever configuration, primary metrics, and statistical analysis plan.
