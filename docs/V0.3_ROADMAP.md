# v0.3 roadmap — Evidence-Family Benchmark

v0.3 turns the architecture demo into the first testable cross-paper reasoning dataset.

## Objective

Construct **10–15 expert-reviewed papers** arranged into **2–3 matched evidence families**, then create claim-pair gold labels that can evaluate whether shared Paper Skills preserve cross-paper relations better than alternative architectures.

## Candidate evidence families

1. **Means restriction / charcoal-burning prevention**
2. **Media reporting / celebrity-suicide effects**
3. **School/youth gatekeeper or mental-health promotion interventions**

## Work packages

### WP1 — Corpus freeze
For every paper, record immutable ID, DOI/source URL, bibliographic metadata, and checksum.

### WP2 — Evidence Cards
Validate population, intervention/exposure, comparator, outcome, study design, effect estimate, uncertainty, limitations, and applicability.

### WP3 — Claim-level provenance
Every benchmark claim must map to a page, table, figure, or exact source span.

### WP4 — Gold relation graph
Experts adjudicate matched claim pairs as:
`SUPPORTS`, `CONTRADICTS`, `QUALIFIES`, `NOT_COMPARABLE`, or `UNRELATED`.

### WP5 — Matched architecture runners
Run the same questions and evidence budgets through:
- RAG-only
- monolithic agent
- one-paper-one-agent
- Paper-as-Skill

### WP6 — Evaluation
Primary outcomes:
- cross-paper relation accuracy;
- claim-level provenance precision/recall;
- evidence coverage;
- contradiction vs heterogeneity resolution;
- calibration/abstention;
- safety compliance;
- latency/tokens/API calls;
- coordination-message burden.

## Exit criteria

v0.3 is complete when:
- all included Paper Skills are expert reviewed;
- gold claim-pair relations have adjudication notes;
- the four architecture runners can execute against the same frozen benchmark;
- no performance claim is made without matched evaluation.
