# Flagship Case v1 — Retail Charcoal-Access Restriction

## Purpose

Before the 36-cell comparative pilot, run one end-to-end Virtual CSRP case that is scientifically meaningful within suicide prevention and requires several institutional functions.

## User question

> Given the short-term positive intervention evidence, the longer-term New Taipei findings, implementation limitations, and the regional observational context, should a suicide-prevention policymaker consider restricting retail access to barbecue charcoal? Provide a concise evidence memo covering supporting evidence, limiting evidence, implementation conditions, uncertainty, transferability, and remaining evidence gaps.

## Why this is the flagship case

The case requires:

- intervention-effect interpretation;
- comparison of short- and longer-term evidence;
- implementation reasoning;
- distinction between intervention and observational evidence;
- uncertainty and transferability;
- a policy-facing output rather than a simple literature summary.

## Virtual CSRP flow

```text
Policy question
    ↓
Director / PI Agent
    ↓
Chief of Staff / Query Router
    ↓
Intervention & Evaluation
Policy & Implementation
Methods & Evidence
(+ Surveillance when relevant)
    ↓
Shared Means-Restriction Paper Skills
    ↓
Evidence Judge
    ↓
Safety Supervisor
    ↓
Policy Intelligence memo
```

## Required output

The memo should contain:

1. Evidence supporting consideration
2. Evidence limiting confidence
3. Implementation conditions
4. Uncertainty and transferability
5. Evidence gaps
6. Bottom-line policy interpretation

The bottom line should be conditional and evidence-weighted rather than a universal policy claim.

## Interpretation boundary

This is a population-level research/policy case. It does not provide an individual suicide-risk estimate or clinical recommendation.
