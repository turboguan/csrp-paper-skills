## What this freeze means

The goal is reproducibility, not software immobility.

This branch should not receive conceptual changes to the organizational architectures once comparative pilot execution begins. New ideas should be developed on a new versioned research branch.

If a bug threatens validity, fix it on a new branch and document:

1. the bug;
2. the affected cells/results;
3. the correction;
4. whether earlier results must be invalidated or rerun.

## Scientific status

This is a **pre-pilot architecture freeze**. It does not imply that any architecture is superior, clinically useful, or validated on the full CSRP corpus.

The near-term scientific focus remains suicide-prevention evidence synthesis.
